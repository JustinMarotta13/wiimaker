# Editor memory

Operational notes for `wiimaker-editor` and shared `wiimaker-scene` mutate UX.

Canonical rules: `.cursor/rules/wiimaker-editor.mdc`.
Visual 1:1: [unity-chrome.md](./unity-chrome.md) (crops from Unity 6000.5 dark).

## Gotchas

- After mutate helpers, always set dirty + `rehydrate()` before relying on World/viewport.
- Inspector numeric fields are Unity-style XYZ DragValues (not sliders). Undo: `begin_inspector_gesture` once per drag; sync baseline on release / after discrete mutates.
- Discrete edits (add/remove/rename/duplicate/paste/components/reparent): `push_undo()` then mutate, then `sync_baseline()`.
- egui_dock Unity layout (Hierarchy | Scene+Game | Inspector, Project+Console bottom). Scene blit fills the leaf; never letterbox a 640×480 postage stamp beside Hierarchy. Map picks with `pointer_to_scene` on the image rect (= well). Never `set_min_width(available_width())` on dock panels. Virtualize Hierarchy rows when a parent has hundreds of children.
- Sprites use catalog pivot by default (center): dest = translation − pivot × size × scale. Optional `SceneSprite.pivot` overrides per entity; pick / selection outline / `render_world` share that math.
- Viewport drag translate: push one undo snapshot at drag **start** only (not per frame). Use `set_entity_world_xy` so children keep correct local pose under parents.
- After open-scene: set `scene`/`scene_path`, `dirty = false`, clear selection + undo stack, then `rehydrate()`. Do not rewrite `game.toml` just to preview another scene.
- Dirty switch uses `pending_open` + egui "Unsaved changes" modal (Save / Discard / Cancel).
- Dock splitters resize leaves (Hierarchy / Inspector / Project). Do not wrap those in SidePanel/TopBottomPanel or `set_min_width(available_width())`.
- Hierarchy DnD payload is `String` entity name; drop on **Scene** row unparents; drop on a row parents under it. `set_entity_parent` rejects cycles and preserves world pose.
- **Hierarchy click vs drag:** do **not** use `dnd_drag_source` for selectable rows. It overlays `Sense::drag()` on top of the row; egui then ignores click widgets underneath, so drag starts immediately and Inspector selection never fires. Use `Sense::click_and_drag()` + `dnd_set_drag_payload` (+ Tooltip layer ghost while `is_being_dragged`). Labels: `.selectable(false)` so text-select sense does not compete.
- Toolbar primary: Save · Play · Build · Play in Dolphin · Build & Run. **Cook** lives under the painter ellipsis menu only. Host Play and Wii Build auto-prepare assets.
- Sprite / Disc Inspector: checkbox toggles `enabled` (skipped by hydrate/pick/bake); Remove uses `remove_component_*`. CLI: `entity remove-component` / `set-component-enabled --enabled true|false`.
- Viewport: Snap checkbox + grid size; Scene **Hand** pans (middle-drag also pans); scroll + `%` zoom; **Grid** overlay; **Gizmos** toggle (colliders/tilemaps/camera); Move handles are independent of that toggle. **2D** is always-on. Arrow keys nudge 1px (or snap size when Snap/Shift). Multi-select via Cmd-click (Hierarchy + viewport); drag moves whole selection; Delete on a selected row removes all selected.
- Play toolbar = in-editor Play Mode (Play/Pause/Step/Stop, Esc stops). Loads the game `cdylib` (`export_play_app!`) and ticks `App::update`. No plugin → WASD / `Player` + OrbShadow fallback. **Step** calls `PlaySession::step_one` (exactly one 60 Hz frame) then stays Paused. Stopped: enter Play, one frame, pause. Playing: the next host frame is that single step (the click frame's tick already ran). Scene edits preserved on Stop. Play tick errors call `stop_play` (restores docks). Opening another scene while Playing also calls `stop_play` first. File → Run external… still shells `cargo run -p <game>`. CLI twins: `editor play-status`, `editor play-step --frames N`.
- Game view right side (2026-10-20): **Play Focused** / **Play Maximized**, **Mute Audio**, **Stats**. Maximized, on entering Play, replaces the dock with a single Game tab; Stop (or scene switch / play error) restores the previous `DockState` (`play_layout.rs`). The dropdown lives inside the dock, so a change sets `play_layout_sync` and applies after `DockArea` puts the real tree back. Mute uses `HostAudio::consume_oneshots(..., mute)` on the editor World and `SuppressAudio` (`WIIMAKER_AUDIO=0` for the plugin's own host player) around the tick. Stats reads measured `unstable_dt` (no number until a sample exists), `live_entity_count`, and `DrawList::stats` (sprites / text / quads / discs) from the blit. Prefs: `game_view.play_mode` / `mute_audio` / `stats`. Screenshot envs: `WIIMAKER_EDITOR_SHOT=path` (gizmo proof), `WIIMAKER_EDITOR_TAB=Game`, `WIIMAKER_EDITOR_PLAY=1`, `WIIMAKER_EDITOR_STEP=1`, `WIIMAKER_EDITOR_STATS=1`, `WIIMAKER_EDITOR_PLAY_MENU=1`, `WIIMAKER_EDITOR_SCREENSHOT=path` (frame 24).
- Viewport tools: Move · Scale · Rotate · Hand. **Move** draws red X / green Y axis handles (+ XY square). **Rotate** draws a blue Z ring (faint outer ring); a drag sweeps Z, Snap or Ctrl snaps to 15°, and the drag paints a translucent wedge plus a degree readout. **Scale** draws red/green shafts ending in cubes and a grey center square (X/Y axis, center uniform; magnitude clamped, never zero). **Pivot / Center** and **Local / Global** are Scene toolbar buttons (dark Pro) stored in prefs. Local rotates Move and Scale axes with the active entity's world Z (Move X/Y follows those axes). Global keeps them world-aligned. Scale always writes local scale. Center uses the selection-bounds center when more than one entity is selected; Rotate/Scale orbit that point. A single selection uses the entity origin for both. One undo step per drag (`push_undo` at drag start, `sync_baseline` on release — same as Move). Hit-test / drag math: `gizmo.rs`. Hover and the active axis turn yellow (`theme::HANDLE_HOT`). Entity-body drag, Hand, and Paint/Erase/Pick are unchanged. `WIIMAKER_EDITOR_GIZMO=rotate|scale|toolbar` poses a proof shot (rotate also draws a demo wedge; does not write prefs by itself).
- Tilemap: viewport **Paint / Erase / Pick** (right-click erases while Painting). Inspector **+ Tilemap** (32×18, cell 16) · grid w/h · cell · origin · palette (id/color/sprite/**Anim**/Override FPS/**Auto Tile** Off·Same id·Solid/Variants) · **Brush** · **Import ASCII** (project `.txt`, same `tilemap_from_ascii_path` as CLI). Palette id DragValue is `1..=u16::MAX` (CLI `--id` is `u16`; do not clamp to 32). Painted NESW badge next to Brush when auto-tile is on. Selected tilemap AABB outlined; paint stamps `tile_brush_id` + solid onto the targeted grid. Hover status shows `mask`. Scene **Edit** ticks palette anims (`World::tick_tilemaps`) so water/lava preview without Play. Project: `.txt` rows → **Stamp into Tilemap** / **Import into new Maze**; drop TXT copies into `assets/`.
- Collider Inspector: solid · **Is Trigger** · **Filter Tag** (0 = any). Viewport gizmos (when **Gizmos** is on): seafoam fill+outline+corner ticks for AABB, fill+cardinals for circles; amber (`220,180,60`) for triggers. Tilemaps get bounds + cell grid. Keep dark theme.
- Camera Inspector: Follow target combo (entity names) + Lerp. Scene view draws a 640×480 cyan rect centered on the active camera (Game tab applies offset). Play (plugin or fallback) ticks `World::follow_cameras` after movement / GridMover.
- GridMover Inspector: Cell, Speed, queued cardinal combo. Add Component → GridMover. Template `App` and fallback Play: `step_grid_movers` from WASD/arrows; if Player has GridMover, skip free WASD.
- Animation Inspector: clip combo + Override FPS + Loop. **Animator** foldout: controller combo (`*.controller.json`), current state (read-only while Playing), Bool/Trigger checkboxes + Float drags (live on Play World; persist as scene overrides in Edit). Add Component → Animator. Project labels `*.controller.json` as Animator controller.
- Timeline curves (2026-10-07): Transform/Float rows in the Timeline dock expand into curve lanes (X red / Y green / Float blue). Key drag, add/delete, and interpolation call `wiimaker-assets` `curve_*` helpers and write the `.timeline.json` (not scene undo). Selected key `t`/`v` DragValues sit in the dock header and the asset Inspector. Preview playhead is restored after the asset reload. Lane context menu stores the pointer and hit index at `secondary_clicked` (egui temp data). The popup covers the lane, so `hover_pos` / `interact_pointer_pos` are None while it is open. Right-click on a diamond also selects that key. `curve_lane_pointer` maps screen x → clip-local t.
- **Playable Director** foldout: timeline combo (`*.timeline.json`), Play On Awake, Loop, live time, Play/Stop, scrub slider. Bottom dock **Timeline** tab (next to Project/Console) draws track rows + clip rects + playhead. **Signal** rows are diamond markers (geometric, not a Unicode pin) labeled with the signal name. **Control** clips are rects labeled with the target entity. Dark Pro only. Edit-mode Play on that transport sets `timeline_preview` (ticks directors without Play Mode). Stop rehydrates so the viewport returns to the authored pose. Project `.timeline.json` inspector edits duration and lists tracks (kind name, Signal marker times, Control target). **Add Signal Marker** / **Add Control Clip** on the Timeline dock and the asset Inspector write `assets/<stem>.timeline.json` (same save path as Duration). Asset writes are not on the scene `UndoStack`. Editor Play and Timeline preview log `signal <name> @ t (binding)` to the Console (Info) via `take_timeline_signals` after the tick. Double-click focuses the Timeline tab.
- Sorting layers: Inspector Sprite/Disc/Tilemap/Text **Sorting Layer** combo + **Order in Layer** (`z`). Project `game.toml` inspector: ordered list with ↑↓, –, select + draft **+ Add** / **Rename**. Mutate helpers in `wiimaker-scene` remap other scenes/prefabs on rename/remove; editor remaps the open scene in memory.
- Sprite Inspector: **Pivot** X/Y DragValues (normalized; catalog values shown when not overridden, muted hint). Editing writes `SceneSprite.pivot`. **Reset** clears the override (catalog again).
- Scene **Environment** / **Clear Color**: Inspector shows it when nothing is selected (replaces bare "None") and when the open `.scene.json` is selected in Project. Color drag uses `begin_inspector_gesture` once; **Reset** is discrete `push_undo` then `set_scene_clear` (RGB, A=255) then `sync_baseline`. Viewport blit already uses `scene.clear_rgba()`. CLI twin: `scene set-clear --rgb` (unchanged).
- **Input** card (same empty-selection / open-scene surfaces): live host keyboard → GCN-layout stick / D-pad / A/B/Start plus **IR** x/y + Valid badge plus **Accel** XYZ + Motion Valid + Gesture (Shake/Swing) badges; legend includes IR / motion / Shift+mouse tilt. Game view paints stick overlay + IR crosshair + accel XYZ bars while Playing/Paused. `live_input` is sampled every frame (`apply_pad_keys` + mouse→IR over Game letterbox + Shift→accel); Play tick reuses it. CLI twin: `input map`. Dark Pro only — no light chrome.
- Text Inspector: string (multiline), Size, Color, Align combo, Sorting Layer / Order in Layer. Add Component → Text. Host bitmap HUD; Wii GX draws via `KIND_TEXT`.
- Prefabs: scene entity `prefab` field (relative `*.prefab.json` or stem; missing = not an instance). Instantiate / Save as Prefab records the link. Inspector instance card: **Apply** (push to asset) · **Revert** · **Unpack Completely**. Overridden Transform/component labels are orange+bold (`theme::PREFAB_OVERRIDE`) on dark Pro. CLI: `entity create-prefab` / `instantiate-prefab` / `apply-prefab` / `revert-prefab` / `unpack-prefab` / `prefab-status`. Nested prefabs + variants shipped; Apply to Base / Open Base (2026-10-05) below.
- Prefab variant Apply to Base / Open Base: instance header **Base:** name · **Open Base** / **Select Base** (`focus_base_asset` — both select the base `.prefab.json`; expands collapsed Project ancestors). **Overrides** menu uses `prefab_variant_chrome` labels. Per-field apply/revert and Apply All to Base call `apply_instance_fields_to_prefab` / `apply_instance_to_base` / `revert_prefab_instance_fields` (field revert `push_undo`s the scene). Asset writes are not in `UndoStack`. Variant `.prefab.json` Inspector lists stored overrides with **Apply to Base** / **Revert to Base**. Empty `overrides` means effective overrides = snapshot-vs-base (`resolve_prefab`). Apply to Base copies onto siblings only when that path is **not** in the sibling's effective list vs the **old** base (plan before writing). Explicit listed overrides skip the copy; a legacy empty-override sibling with a divergent snapshot keeps its value. Pristine empty-override siblings (snapshot matched old base) still inherit. After Apply to Base / Root / field / whole-tree Apply, other open-scene instances whose prefab chain includes the written asset inherit paths they did not override (`scene_synced`). Editor marks the scene dirty and keeps one undo step when that list is non-empty (`UndoStack::discard_latest` otherwise). `--to-root` keeps an intermediate variant's own different value.
- Multi-select: status `selected N: A, B`; Hierarchy uses full-width blue selection (Unity), not `>`/`+` prefixes.
- Drop PNG/WAV/TXT anywhere in the editor window → copy into `assets/` + cook refresh (TXT skips cook).
- Sprite Editor: Project file (PNG / `.sprites.json`) → Inspector **Edit Sprites…**, or double-click / context menu; writes `.sprites.json` then refresh catalog.
- Project panel is a **file explorer** (`game.toml`, `assets/`, `scenes/`). Click → `selected_file` (clears entity selection); Inspector shows path/type/size + type-specific actions.
- Project Search (session-only `project_filter`, Hierarchy chrome: `search_icon` + hint "Search") filters filename / relative path case-insensitively. Matches auto-reveal ancestor folders (collapsed prefs unchanged while filtering).
- Console Search (session-only `console_filter`, same `search_icon` + hint "Search") filters log lines case-insensitively on text **or** level tag (`info`/`warn`/`error`). Session-only `console_show_info` / `console_show_warn` / `console_show_error` (default all on). Count: `N messages` or `k / N messages` while filtering — raw messages, not collapsed rows. Toolbar order: **Clear** (split button + geometric dropdown) · **Collapse** · **Error Pause** · **Doctor** · Search · message count · Info/Warn/Error totals. Prefs `[console]` in `.wiimaker/prefs.toml`: `clear_on_play` (Unity default **on**), `clear_on_build`, `collapse`, `error_pause` (default off). Old files without `[console]` load those defaults. Search text is not stored. CLI: `editor set-console` / `editor prefs`. Screenshot helper (does not write prefs): `WIIMAKER_EDITOR_CONSOLE=collapse|menu|error-pause` with `WIIMAKER_EDITOR_TAB=Console`. `error-pause` enters Play if stopped and logs one Error through `log_line`, the same funnel as a failed tick.
- Clear on Play clears inside `begin_play_session` (Play or Step from Stopped) before the new Play logs. Unpause does not clear. Clear on Build clears at the start of Build, Build & Run, and Play in Dolphin.
- Collapse groups lines with the same level and the same text, including repeats that are not adjacent (first-seen order). A count badge is painted on the right of the row when the group count is greater than 1. Level toggles and Search hide groups; the badge count is the full group size.
- Error Pause: `console_push` of an Error while `PlayMode::Playing` sets Paused and keeps the session. Games cannot log to the Console (`App::update` is `()`; no new log API). Real sources: `play tick: …` when `PlaySession` returns `Err` (plugin update/render non-zero). With Error Pause off, that path still calls `stop_play`. With it on, the session stays and Play is Paused. Doctor and other editor `log_line(Error)` calls during Play use the same pause. Startup fallback strings stay Info, so they do not trip Error Pause. `editor play-step --json` reports `paused_on_error` when a headless tick fails and the pref is on.
- Project folders: geometric `foldout_button` (not Unicode ▶/▼) + `#` marker. Triangle click toggles collapse without selecting; row click selects for Inspector; double-click folder toggles. Collapsed relative paths persist in `.wiimaker/prefs.toml` `project_view.collapsed` (empty = all expanded). CLI: `editor set-project-view` / `editor prefs`.
- Project rows: full-width painted hover/select (not `selectable_label`); folders use accent + strong text — never `TEXT_MUTED` for primary labels. ASCII type markers only (Unicode glyphs fail in this shell).
- **Icons must be painter geometry** (`theme::{cube_icon, foldout_button, enable_checkbox, icon_menu_button, play_control, search_icon, tool_toggle}`). egui default fonts on this Linux box do not rasterize `▾ ▸ ⋮ ⋯ ▶` (or a hollow `rect_stroke` cube, which reads as tofu). Do not use Unicode/emoji as icons. Geometric stand-ins only — never Unity cube/logo artwork.
- Project row `new_child` text: always `set_clip_rect(row_rect.intersect(ui.clip_rect()))`. Replacing the ScrollArea clip lets scrolled-off labels paint over the Project header/meta chips.

## Decisions

- Editor sources are modular: `main.rs` entry · `app.rs` (`EditorApp` state / mutate / `update` orchestrator) · `ui_toolbar` · `ui_hierarchy` · `ui_inspector` · `ui_project` · `viewport` · `workspace` · `theme` · `sprite_editor`. Panel methods are `impl EditorApp` in sibling files.
- `UndoStack` lives in `wiimaker-scene` (snapshot of `Scene`, depth 50).
- Duplicate/paste share `insert_entity_clone` (+16,+16, `unique_entity_name`).
- Hierarchy: Search + Create Empty / right-click Duplicate·Delete; shortcuts Cmd/Ctrl+D/C/V/Z/Shift+Z/Y. No per-row D/x (see unity-chrome crops). Left gutter: eye (Scene visibility) and hand (pickability). Hover shows both; slashed icons stay when hidden or unpickable; a mixed parent is dimmed with a dot. Click applies to descendants; Alt-click is that row only. Hidden entities are skipped by the Scene-view draw filter and by Scene click/box pick while `[scene_visibility].enabled` is on. The Scene toolbar eye-with-slash toggles that without clearing lists. Unpickable entities stay drawn. Game view, Play, and bake do not read this. Prefs live in `.wiimaker/prefs.toml` (not the scene). Rename/delete retarget or drop names; unknown names are ignored. Screenshot helper `WIIMAKER_EDITOR_HIER_HOVER=<name>` paints that row's icons without writing prefs.
- Editor chrome: `theme.rs` teal-accent charcoal Visuals; panel frames, section headers, centered viewport well. Apply via `theme::apply` in eframe CreationContext.
- P0 viewport pick/drag lives in `wiimaker-scene` (`pick.rs` + `gizmo.rs`) + editor `handle_viewport_input`. Topmost = highest Sorting Layer, then order-in-layer `z`, then later entity index.
- Translate / rotate / scale gizmos: `MoveHandleLayout`, `RotateHandleLayout`, `ScaleHandleLayout` in screen pixels. Drag math (`rotation_after_drag`, `scale_factors`, `constrain_translate_oriented`, `gizmo_origin`) is unit-tested in `gizmo.rs`. Prefs + CLI: `handle_position`, `handle_rotation`, `tool`.
- Scene discovery: `wiimaker_scene::list_scenes(game_dir)` → relative `*.scene.json` under `scenes/` plus `default_scene` if outside that dir.
- Opening a non-default scene is editor-only preview; "Set as default scene" persists via `save_project`.
- File → **Build Settings…** (also Project / Inspector on `game.toml`): ordered `game.toml` `scenes` list, star = `default_scene`, +/- add/remove, Open. CLI twins: `scene build-list` / `build-add` / `build-remove`.
- Entity hierarchy: optional `parent` name on `EntityData`; transform is **local**; hydrate/pick/wscn/outline compose world via `Scene::world_transform` (full TRS: parent rotation orbits children). Delete cascades to descendants. CLI: `entity set-parent --name X [--parent Y]`.
- Inspector sprite field is a catalog ComboBox (cells + whole textures), not PNG stems only.
- Inspector focus is entity XOR project file (`selected` / `selected_file`). Empty selection still shows the open scene's Environment / Clear Color card (not a GameObject).
- Scene clear color lives on `Scene.clear_color` (`[u8; 4]`, default `DEFAULT_CLEAR_COLOR` `[12,18,32,255]`). Editor Environment picker + CLI `scene set-clear` both call `set_scene_clear`. WSCN bake writes the 4 bytes after magic.
- Scene/Game/Project chrome prefs: `<game>/.wiimaker/prefs.toml` (`EditorPrefs` in `wiimaker-scene`). Not `game.toml`. Editor toolbar + `scene set-game-view` / `editor set-scene-view` / `editor set-project-view` share `load_editor_prefs` / `save_editor_prefs` (atomic temp+fsync+rename). Scene zoom 1 = fill well; Game **Free** fills the well (Unity Free Aspect); **Play Maximized + Free** letterboxes 640×480 via `game_view_blit_rect(..., play_maximized)`. Locked presets use their aspect + Scale slider. `clamp_viewport_well_size` before blit when egui reports infinite available width. Project `collapsed` is relative folder paths; Search filter is session-only. Scene view also stores `tool` (move/rotate/scale/hand/paint/erase/pick), `handle_position` (pivot/center), and `handle_rotation` (local/global). **Missing keys / old projects without prefs:** Move, Pivot, **Local** handle rotation (not Global). Rotate/Scale gizmo drags skip selected descendants when a selected ancestor is also selected (`gizmo_has_selected_ancestor`); rotate wedge/readout uses unwrapped pointer sweep per drag.
- Selection is `Vec<String>` (last = primary for Inspector); Cmd-click toggles.
- Controller asset Inspector (`ui_controller.rs`, opened from `ui_inspector_file` on `*.controller.json`): a Layers list (Base + overrides) with weight DragValue, **Add Layer** / **Remove**, then that layer's states. Blend edits build a whole `BlendTreeMeta` working copy, then write through `write_layer_state_blend_tree` / `write_layer_state_clip` (base still goes through the unscoped wrappers), then `reload_assets()` + `rehydrate()`. Never write the JSON directly, so GUI and CLI stay identical. 2D is disabled with fewer than two Float params. Changing dimension converts thresholds ↔ positions in the same frame (`convert_dimension`). Layers are Override only (muted hint). Asset writes are not on the scene UndoStack. Weight DragValues keep finite out-of-range values raw (runtime clamps 0..1). Base weight is disabled (playback ignores it).
- Animator layer rename/remove (2026-10-15): window + controller Inspector use `rename_controller_layer_for_game` / `remove_controller_layer_for_game` (`skip_scene` + in-memory remap) so open-scene `Animator.layers` weight overrides stay in sync. Inspector DragValue still calls `SceneAnimator::set_layer_weight` (canonical `Base`).
- Animator window (2026-10-14): bottom dock tab. `WIIMAKER_EDITOR_TAB=Animator` focuses it on open (screenshot helper, with the existing `WIIMAKER_EDITOR_SELECT` / `WIIMAKER_EDITOR_PLAY`). `WIIMAKER_EDITOR_SIZE=1600x1100` and `WIIMAKER_EDITOR_BOTTOM=0.48` enlarge the window and bottom leaf for those shots. Graph layout and hit tests live in `wiimaker-assets::animator_graph` (no egui). Node positions are optional `position` / `graph` fields; omit them and resave stays byte-stable. Context-menu hit is stored at `secondary_clicked` because the popup has no hover pos. Asset writes are not scene undo. Live Play progress reads `Animator::layer_normalized_time` from the play session world.
- Entity Animator foldout shows **Playback** (winning layer · state), then each layer's state, weight DragValue, and blend line (`Blend · Speed 50% → idle`). Edit-mode weight calls `set_entity_animator_layer_weight` (scene override, undo via the inspector gesture). Play-mode weight calls `World::set_animator_layer_weight` and does not write the scene. Blend-tree authoring stays on the controller asset.

## computer-control MCP (2026-07-24)

- `list_windows` does **not** see `wiimaker-editor`; `activate_window("wiimaker"|"hello-orb")` fuzzy-hits Cursor/Chrome. Use System Events `frontmost` + `screencapture -l` / OCR.
- Launch editor from **Terminal.app** with the same `CARGO_TARGET_DIR` as the agent build (or invoke the debug binary path directly) — otherwise Terminal may run a stale `target/debug` binary.
- `screencapture -l` images include shadow padding (~56px); map OCR with `pad=(img-win)/2` (mapB) for toolbar Y. Mid-window Hierarchy mapA≈mapB; toolbar mapA is ~46px too low.
- MCP `click_screen` / CGEvent / System Events clicks can silently stop affecting the editor mid-session (TCC/focus). Prefer CLI `--json` + OCR status proofs; editor Prefab Instantate has **Cmd+I** as a non-click path.
